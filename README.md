# خطوط ستوديو | Lines Studio

موقع الوكالة: الصفحة الرئيسية، ومعرض التصاميم، وصفحة طلب الموقع. بالعربي (`/ar/`) والإنجليزي (`/en/`).

## قبل الإطلاق

عدّل `lib/site.js`:

- `whatsapp`: رقم الواتساب بالصيغة الدولية بدون + (مثال `9665XXXXXXXX`). أزرار "خلنا نسولف" وطلبات المعرض كلها تروح له.
- `email` و`crNumber`: يظهرون في الفوتر.

- قسم «فيديو إطلاق لموقعك» في الرئيسية يعرض العيّنة `public/video/launch-3d-ar.mp4`. السعر «حسب الطلب» لين يتقرر التسعير.

### إحصاءات الزيارات (اختياري)

أداة إحصاءات مستضافة عندنا بدون كوكيز (Umami على Coolify). عرّف متغيري البناء `NEXT_PUBLIC_ANALYTICS_SRC` (رابط `script.js`) و`NEXT_PUBLIC_ANALYTICS_ID` (معرّف الموقع في Umami) في Coolify كـ Build Variables. لو فاضيين ما يتحمّل أي سكربت. يتسجّل حدث `whatsapp` مع مكان الزر (`header`، `footer`، `package-1..3`، `trial`، `video`)، وحدث `order` عند إرسال الطلب (التصميم، الحجم، وهل فيه فيديو).

### الخصومات وأكواد الخصم

في `lib/promo.js`:

- `launchOffer`: خصم الإطلاق (حالياً 30%) على كل الأسعار المعروضة، مع السعر القديم مشطوب. `pct: 0` يوقفه، و`ends` تاريخ نهاية اختياري. الموقع ثابت، فأي تغيير يحتاج إعادة بناء.
- `promoCodes`: الأكواد محفوظة كبصمة SHA-256 عشان ما تنقرى من كود الموقع. أضف كود بـ `node scripts/promo-hash.mjs CODE` وحط البصمة مع النسبة والنطاق (`sites` أو `social` أو `all`) وتاريخ الانتهاء. لا تكتب نص الكود في تعليق. الكود يطبّق فوق خصم الإطلاق، ويوصل مع رسالة الواتساب وبجانبه تنبيه إن الفريق يتحقق منه قبل الدفع.
- السعر النهائي يتأكد في عرض السعر ورابط الدفع. فحص الكود في المتصفح للعرض فقط.

## التشغيل محلياً

```bash
npm install
npm run dev      # http://localhost:3000/ar/
```

## البناء والنشر

```bash
npm run build    # يطلع موقع ثابت في مجلد out/
```

**على Coolify:** أضف المشروع من الريبو، واختر Dockerfile (موجود في المشروع). يبني الموقع ويقدمه عبر nginx على المنفذ 80. أو اختر Static وحدد مجلد النشر `out`.

## واجهة الفيديو

الموقع الثابت يبقى على nginx كما هو. توليد الفيديو خدمة منفصلة: `services/creative-api/` على Coolify كتطبيق مستقل (الهدف `api.lines.studio`)، وعامل السحب على الماك ميني في `services/mac-video-worker/`. تطبيقات اكسبرتو تنادي الواجهة من خادمها. تطبيق الجوال لا يحمل مفتاح الواجهة. العقد في `docs/video-api.openapi.yaml` و`services/creative-api/README.md`.

## فيديوهات ترويجية ثلاثية الأبعاد (Blender)

مشروع `services/blender-3d-promo/`: فيديو ترويجي ثلاثي الأبعاد كامل من ملف JSON. الكود يبني مشهد Blender (جوال أو لابتوب يعرض لقطة الموقع، أو كرة بشعار) مع خطوط مضيئة وحركة كاميرا، ويكتب النص العربي فوقه بـ ffmpeg.

```bash
cd services/blender-3d-promo
BLENDER_BIN=/Applications/Blender.app/Contents/MacOS/Blender node src/cli.js examples/experto-ar.json --quality draft
```

ويشتغل أيضاً عبر واجهة الفيديو بـ `style: "promo3d"` مع عامل Blender على الماك ميني. التفاصيل في `services/blender-3d-promo/README.md`.

## فيديوهات UGC

`services/ugc-worker/`: فيديو بأسلوب شخص يصوّر نفسه ويتكلم عن المنتج. تطلبه التطبيقات من واجهة الفيديو بـ `style: "ugc"` مع نص جاهز ومقدّم (`metadata.presenter`). العامل يولّد الصوت من ElevenLabs، ويحرّك صورة المقدّم مع مطابقة الشفايف على fal.ai، ويكتب الترجمة. هذي خدمات مدفوعة. التفاصيل في `services/ugc-worker/README.md`.

## محتوى السوشال ميديا وإدارة الحسابات

صفحة `/ar/social/` فيها باقات إدارة الحسابات الشهرية (الأسعار والكميات في `lib/social.js`). أداة الفريق لكتابة المحتوى في `services/social-content/`: من ملف وصف للعميل تطلع تقويم الشهر كامل بالسعودي (منشورات، ريلز، ستوري، تغريدات) عبر Claude، مع ورقة مراجعة وملف CSV للجدولة، ونصوص الريلز جاهزة كطلبات UGC لواجهة الفيديو. التفاصيل في `services/social-content/README.md`.

## إعلانات: توطين إعلانات الفيديو

صفحة `/ar/ads/` («إعلانات» في القائمة): طلب نسخة سعودية من إعلان فيديو جاهز، بتبديل الشخصيات واللبس والمنتج والخلفية، مع ترجمة أو تعليق صوتي باللهجة. النموذج يجهّز رسالة واتساب مثل نموذج الطلب، والسعر حسب الطلب. تبديل الشخصيات أو الصوت ما يمشي إلا بتأكيد العميل إن عنده الحق. النصوص والخيارات في `lib/ads.js`، ونفسها تستخدمها أداة `request_ad_localization` في سيرفر MCP.

وفي واجهة الفيديو فيه `style: "localize"` (مقفول افتراضياً بـ `LINES_ENABLE_LOCALIZE`). الواجهة تستقبل الطلب وتتأكد منه وتحفظه وتعرض تقدير التكلفة قبل التشغيل (سقف `LINES_LOCALIZE_MAX_USD`، الافتراضي 15 دولار). التنفيذ على عامل السحب في `services/localize-worker`: Runway Aleph 2.0 للتبديل البصري، ثم HeyGen Precision للترجمة إلى `Arabic (Saudi Arabia)` مع مزامنة الشفايف. ما فيه إطلاق ولا استدعاء مدفوع حي في هذا الفرع. وفيه ثلاث باقات بـ `localize.tier`: `free` (مجاني على الماك: صوت سعودي محلي ومزامنة شفايف MuseTalk، بدون تبديل)، و`economy` (تبديل Gemini Omni Flash بدقة 720p مع الصوت والشفايف المحلية، تقريبًا 2.10 دولار لكل 30 ثانية)، و`pro` (الافتراضي: Aleph مع HeyGen، تقريبًا 9.15 دولار). التفاصيل في `services/creative-api/README.md`.

## إضافة تصميم جديد للمعرض

أضف عنصر في `designs` داخل `lib/designs.js` بنفس الشكل: `id` و`cat` والاسم والوصف بالعربي والإنجليزي، وألوان المعاينة.
